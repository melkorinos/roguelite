# T2 cross-combo scope: 24 of 39 pairs

The 6 deferred T1 elements (Lightning, Nature, Light, Dark, Metal, Sound) each have self-combos but were added without cross-combos. When implementing them, we chose to add only cross-combos with the original 4 T1s (Water, Fire, Air, Earth) — 24 pairs — rather than all 39 (which would include the 15 pairs among the 6 new elements with each other).

The 15 new-to-new pairs (e.g. Lightning + Sound, Dark + Metal) were skipped because they lack obvious thematic anchors, would produce 15 more T2 elements with no existing T3 upgrade paths, and would have roughly tripled the new-element count in a single session. The 24 new-to-original combos already triple the T2 cross-combo count. The 15 remaining pairs are explicitly deferred — not ruled out.
