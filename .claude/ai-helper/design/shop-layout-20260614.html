Shop Layout Exploration 1920×1080

Reclaiming the wasted screen. Native canvas is 1920×1080 (project.godot canvas_items · expand) — the old layout was a single tall left column that overflowed once cards became w×1.45, hiding the FIGHT button. Goal: 4 areas on one screen, no scroll, cards as big as the layout allows. Each frame restyled to echo the card aesthetic (dark interior · metal-ish border · area-accent glow). Below, each mock is a true 1920×1080 stage shown at 0.6 scale.

Area accents (real ThemeData): Shop = gold/amber merchant · Inventory = cool blue (SHOP_INVENTORY) · Battle board = warm red (SHOP_BATTLEGRID) · Forge = alchemical purple (FORGE_PANEL). Cards use real elements (the Fire chain + Steam) and real stat_pods output.

Card text fix folded in: font hierarchy is now Name (largest) › trigger condition (slightly above body) › body. The bold-blue trigger prefix is shrunk from its current too-heavy size but keeps the style; body + name are bumped up. Bigger cards make all of it readable.
